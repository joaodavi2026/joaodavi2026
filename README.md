### ⭐ Destaques

| Projeto | O que é |
|---|---|

| **OLYMPK Agent** | Agente de atendimento via WhatsApp da Olympk Educação, com IA 100% local (Ollama), base de conhecimento do site e painel administrativo. *(repositório privado)* |
